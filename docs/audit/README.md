# Auditoría

Revisión independiente por ChatGPT y aprobación por el equipo humano. Una auditoría registra alcance, referencia exacta (SHA/PR), requisitos y criterios evaluados, hallazgos por severidad, evidencia, resultado (aprobado/requiere cambios/bloqueado), prompt correctivo y estado de verificación. Nunca afirmar que se ejecutaron pruebas si solo se revisaron archivos o logs. No hay auditorías funcionales todavía.
